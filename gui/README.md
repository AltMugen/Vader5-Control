# Vader5 Control

Графический интерфейс для `vader5`, на GTK 4 и libadwaita. Приложение запускается по необходимости; отдельный сервис для GUI не устанавливается.

Уже подключены:

- Native / Padctl и обновление патча Steam через установленную `vader5`;
- профили Padctl: переключение, редактирование TOML, проверка перед сохранением;
- тестер кнопок, стиков и триггеров; гироскоп и акселерометр, если текущий SDL-драйвер их предоставляет;
- прямое чтение состояния, прошивки геймпада/приёмника и дискретного заряда через HID, независимо от видимости устройства в SDL;
- короткий тест двух моторов рукояток через существующий сервис `vader5-rumble`;
- русский и английский интерфейс, тёмная и светлая темы.
- чтение активного RGB-профиля через USB-донгл: эффект, яркость, период и цвета;
- применение подсветки с обратным чтением, резервной копией и возвратом исходных настроек;
- сохранение локальных пресетов подсветки, включая независимые цвета каналов и покадровые анимации;
- повторное подключение тестера ввода и отображение нажатий, стиков и триггеров в реальном времени.

## О программе

Автор — AltMugen. Переключатель «Экспериментальные настройки» по умолчанию выключен: доступны «Обзор», «Подсветка», Padctl и «О программе». Включение открывает стики, триггеры и вибрацию. Выбор сохраняется между запусками. В Windows Padctl отсутствует, акцент интерфейса синий.

## Стики и триггеры

Редактор меняет встроенный профиль контроллера. Текущий Native SDL получает ранний расширенный поток EF, к которому кривые стиков не применяются автоматически. Подключение обработанного ввода с сохранением дополнительных кнопок и IMU — следующий отдельный шаг. Аппаратные фильтры стиков работают на более ранней стадии. Триггеры используют общий обработанный буфер: в отличие от поздних кривых стиков, их профильное преобразование попадает и в EF.

В Linux кривые стиков доступны только для чтения; аппаратные фильтры ниже остаются доступны для изменения. В Windows редактор меняет профиль обработанного Xbox-ввода.

Во вкладке «Стики» нажмите «Считать активный профиль». Редактор содержит круглая или квадратная форма края и радиальная кривая на девять точек. Чтобы задать мёртвую зону и полный ход, укажите их в параметрах шаблона и выберите форму кривой. График показывает заданную кривую, а не результат всех фильтров прошивки. Пресеты «Линейная», «Точнее у центра» и «Быстрый отклик» — наши шаблоны; они меняют черновик до нажатия «Применить настройки».

Базовые пороги стика отображаются справочно в единицах профиля. Редактор шаблонов использует проценты и кодирует результат в девяти точках; границы мёртвой зоны получаются приблизительными из-за числа точек. Координаты точек кривой приведены к шкале, где 0 соответствует центру, 100 — полному ходу; отрицательные значения сохраняются при чтении. Они используются прошивкой для формирования зоны около центра.

Во вкладке «Триггеры» задайте зону центра и полный ход, затем нажмите «Линейная». Шаблон использует P1/P2, сохраняя Zero/End равными 0/255. Ниже доступны все шесть координат и порогов профиля в шкале 0–255. При ненулевом Zero в разобранной прошивке возможен скачок выходного значения; для обычной мёртвой зоны используйте шаблон. Вибрация триггеров настраивается отдельно во вкладке «Вибрация».

«Вернуть исходные» возвращает только настройки соответствующей вкладки, сохранённые при первом чтении профиля в этой сессии. Перед каждой записью сохраняется полная копия A3, проверяется, что профиль не изменился, и перечитывается результат. Моторы, подсветка и макросы этими регуляторами не переписываются. Применение не сохраняет профиль во flash; настройки могут сброситься при выключении. Формат 7.2 пока заблокирован для записи.

### Аппаратные настройки

Внизу вкладки «Стики» отдельно считываются общие настройки: подавление дрожания и отскока стиков, автокалибровка центра, переназначения в прошивке и быстрое переключение профилей. Недоступные по ответу устройства переключатели заблокированы.

Изменение таймера сна включается отдельной галочкой. Ноль при записи отключает обычный таймер; при чтении ответ 0 не позволяет отличить отключение от заводского режима. При потере связи прошивка может использовать отдельный таймер выключения. Остальные аппаратные настройки применяются без изменения сна, если галочка не выбрана.

## Вибрация

«Считать параметры моторов» загружает активный профиль. Верхняя часть вкладки меняет игровые эффекты: включение основной и триггерной вибрации, силу каждой рукоятки и каждого триггера. Для триггеров редактируются настройки длинного хода; параметры микрохода сохраняются без изменений.

Кнопка «Триггеры при нажатии + основной вибрации» подготавливает зависимый эффект. Выберите силу LT/RT ползунками и нажмите «Применить игровые настройки». В раскрывающихся строках LT/RT доступны источник эффекта, минимальный и максимальный уровни, порог входной вибрации и порог нажатия. Пороги и уровни задаются в шкале 0–255. При выборе основного мотора сначала используется указанный канал, а если он нулевой — другой.

Перед записью приложение сверяет профиль и сохраняет резервную копию, после записи перечитывает результат. Если настройки геймпада изменились извне, сначала считайте их заново. Изменения применяются в память геймпада; сохранение после выключения пока не гарантируется. Запись поддерживается для прежнего формата профиля в ветке прошивок 7.1.4.1–7.1.x.x; для 7.2 она заблокирована.

Нижняя часть вкладки — отдельный короткий тест моторов. Его ползунки не меняют игровые настройки. Для прямой проверки четырёх моторов нужны донгл и закрытые Steam/Padctl.

При первом открытии вкладки подсветка считывается автоматически, если найден донгл и нет незавершённого черновика. «Считать с геймпада» обновляет данные вручную. Затем выберите эффект и нажмите «Применить». Доступны волна, дыхание, градиент, статика, заводской эффект и выключение. Для дыхания можно задать до пяти цветов, для градиента — от двух до пяти. Предпросмотр использует десять RGB-каналов; порядок каналов на корпусе и точная фаза анимации ещё требуют сопоставления.

«Статика по каналам» задаёт независимый цвет каждому из 10 каналов. «Покадровая анимация» позволяет редактировать те же 10 цветов в каждом кадре, добавлять копии кадров, удалять и переставлять их. Плавный переход вмещает до 10 кадров, дыхание — до 5 цветных кадров с промежуточным затуханием. Кисть позволяет выбрать цвет и окрашивать каналы кликами или протягиванием с зажатой кнопкой по сетке и полоске на схеме. При выключенной кисти кнопка цвета открывает стандартную палитру GTK; ручной ввод доступен в редакторе палитры. Кнопка «Предпросмотр» запускает анимацию на схеме; передача геймпаду выполняется отдельно кнопкой «Применить». Нажатие на сегмент схемы выделяет соответствующий канал в редакторе. Черновик кадров хранится локально вместе с настройками интерфейса.

Свой эффект передаётся целиком в память геймпада через штатный RGB-протокол. Держать приложение открытым для воспроизведения не требуется. Прочитанные с геймпада различающиеся цвета каналов сохраняются при загрузке в редактор. Число кадров ограничено форматом прошивки; дополнительные кадры не передаются непрерывно с ПК.

«Вернуть исходное» восстанавливает конфигурацию, впервые прочитанную в этом сеансе приложения. Перед каждой записью копия сохраняется в `~/.local/share/vader5-control/backups/`. При изменении профиля или настроек извне обычное применение останавливается: нужно повторить чтение. «Вернуть исходное» самостоятельно перечитывает актуальную конфигурацию перед откатом. Снимки сохраняются отдельно для каждого профиля в пределах сеанса, включая повторное подключение к тому же HID-пути. «Применить» завершает RGB-транзакцию и сохраняет активный профиль командой AA. Сохранение статики и покадрового эффекта после выключения проверено на 7.1.5.4. AA также сохраняет текущие назначения и макросы; перед записью проверяется неизменность основного профиля и сохраняются копии RGB и основного блока. Версия 7.2 для этой операции заблокирована.

Для настройки RGB закройте Steam и Padctl. Нужен USB-донгл Vader 5 Pro (`37d7:2401`), права hidraw выдаёт существующее правило `vader5 n`. Сохранённые RGB-пресеты находятся в пользовательской конфигурации; загрузка пресета меняет только черновик, геймпад обновляется по кнопке «Применить». Версия приёмника считывается вместе с основной прошивкой. Заряд из HID показывается уровнями, а не точными процентами. Turbo подсвечивается только если драйвер действительно сообщает эту кнопку.

Палитры заводских эффектов в `assets/lighting-presets.json` извлечены из F5-конфигурации официальной Space Station 4.2.2.3. Приложение не запускает официальный софт и не требует его установки.

Для тестирования физических кнопок закройте Steam и нажмите «Запустить тестер». Нажатые кнопки, стики и триггеры отображаются в реальном времени. Кнопка «Переподключить» повторно открывает SDL-устройство. При смене режима и закрытии приложения чтение прекращается. Показания гироскопа выводятся в рад/с, акселерометра — в м/с²; при отсутствии датчика отображается прочерк.

## Первое Bluetooth-подключение

В «Обзоре» нажмите «Подключить Bluetooth», затем «Найти геймпад». Включите Flashplay и отключите контроллер от телефона. Выберите геймпад из списка и нажмите «Подключить»: адрес сохранится, тестер дождётся потока без блокировки окна. Закройте Steam и остановите Padctl перед подключением. При закрытии приложения поиск отменяется. Если во время работы тестера запускается Steam, приложение останавливает чтение при ближайшем обновлении статуса (обычно в пределах трёх секунд), освобождая Bluetooth-подключение.

На Linux используется поиск BlueZ; обязательного системного сопряжения нет. На Windows используется поиск и сопряжение WinRT. В дальнейшем установленная SDL читает сохранённый выбор при обычном запуске Steam. Аппаратные настройки через Bluetooth пока недоступны.

## Доступ и повторное подключение

В «Обзоре» кнопка «Считать состояние» обращается к vendor HID-интерфейсу донгла. Для этого не требуется, чтобы SDL уже показывала геймпад. При появлении нового донгла состояние читается один раз автоматически. «Переподключить» повторяет поиск; если тестер был активен, повторно открывает SDL-ввод.

Кнопка «Разрешить доступ» / «Запретить доступ» показывает действие для текущего состояния. Она меняет только поле разрешения сторонним приложениям из официального SDK, затем перечитывает результат и проверяет остальные флаги. Перед изменением тестер автоматически останавливается. Для ветки 7.2 эта запись заблокирована: обработчик в разобранной main MCU отличается от внешнего SDK. Включение доступа после сброса проверено на прошивке 7.1.5.3 с повторным чтением и сохранением остальных флагов. Для остальных версий ветки 7.1.4.1–7.1.x.x используется та же команда SDK, но отдельной аппаратной проверки не было. При наличии другого владельца запись блокируется. Открытие приложения само разрешение не меняет.

Прямые HID-функции этого прототипа рассчитаны на донгл `37d7:2401`. Работа с проводным устройством остаётся отдельной задачей. Windows-порт с отдельным HID-транспортом и переносимая сборка описаны в `../windows/README.md`.

## Запуск

Нужны Python 3.11+, PyGObject, pycairo, GTK 4.10+, libadwaita 1.5+ и librsvg. Установщик проверяет зависимости и устанавливает приложение и пользовательскую иконку в домашний каталог. При обновлении прежняя версия и launcher сохраняются в `~/.local/share/vader5-control-backups/`. Если библиотек нет, установите их пакетным менеджером своего дистрибутива: в Fedora это `python3-gobject python3-cairo gtk4 libadwaita librsvg2`, в Debian/Ubuntu — `python3-gi python3-cairo gir1.2-gtk-4.0 gir1.2-adw-1 gir1.2-rsvg-2.0`.

```bash
./gui/install.sh
vader5-control
```

Или из исходников:

```bash
python3 gui/app.py
```

Пароль sudo запрашивается отдельным GTK-окном и передаётся непосредственно sudo. GUI не запускается от root. Сообщения консольной утилиты отображаются после завершения операции.

Native GTK 4/libadwaita application for the existing `vader5` utility. Requires Python 3.11+, PyGObject, pycairo, GTK 4.10+, libadwaita 1.5+, and librsvg. Run `./gui/install.sh`, then `vader5-control`. Close Steam and Padctl before reading the physical controller or configuring receiver RGB. Lighting supports read, apply with verification, backups, restoring the original session configuration, and local user presets. Preset loading only changes the draft until Apply is pressed. Apply commits lighting to controller memory using AA; static and frame-animation persistence was confirmed on 7.1.5.4. This firmware command also persists current mappings and macros. Gyroscope and accelerometer are displayed when exposed by SDL. Direct receiver status is independent of SDL visibility. The vibration page edits in-game grip and long-travel trigger settings for legacy 7.1 profiles, including grip-linked trigger effects and thresholds. Writes are backed up and verified; power-off persistence is not guaranteed. Short test pulses have separate controls. The 7.2 profile format remains write-blocked.

Статус SDL в Linux проверяет пользовательский запускатель и ссылки на отдельную библиотеку. Старые отметки подмены файлов Steam больше не используются. Это состояние установки, а не проверка библиотеки уже работающего процесса Steam.

First Bluetooth setup: Overview → Connect Bluetooth → Find controller → select → Connect. The selection is saved for SDL. Close Steam first; Linux also requires stopping Padctl. Linux uses BlueZ discovery, Windows uses WinRT discovery and pairing.
