# Vader5 Control 0.1 — Windows experimental

Экспериментальная переносимая сборка для Windows 10/11 x64.

Распаковать `Vader5Control-0.1-windows_experimental-x64.zip` целиком,
запустить `Vader5Control.exe`. GTK, Python и SDL входят в архив.

- Обзор геймпада, тестер и управление доступом стороннего ПО.
- Подсветка: стандартные эффекты, 10 RGB-каналов, до 10 кадров, кисть и пресеты.
- Вибрация через Xbox-интерфейс с использованием системного XInput.
- Патч SDL3 для Steam. Путь определяется через реестр Valve, диск C не обязателен.
- Bluetooth Flashplay: первое подключение через приложение и сохранённый выбор для SDL.
- Русский/английский интерфейс, светлая/тёмная темы с синим акцентом.
- Экспериментальные страницы стиков, триггеров и вибрации включаются в «О программе».

Перед патчем и аппаратной настройкой закрыть Steam и Space Station.
Оригинальные библиотеки Steam сохраняются для восстановления. Инструкции
по откату — в README Windows. После обновления Steam патч может потребоваться
применить повторно.

## Известные ограничения

Bluetooth может обрываться в Steam. Полного трёхосевого гироскопа в Flashplay
нет. Передача подключения от тестера к Steam требует дальнейшей проверки.
Прежние сборки могли долго запускаться; исправления внесены, но одинаковое
время запуска на разных Windows-системах пока не подтверждено. При проблеме
используйте `Launch.cmd` или `Diagnose-Startup.cmd` и приложите журнал.

Настройки контроллера меняются через донгл. Несовместимая запись профилей
7.2 заблокирована. RGB save также сохраняет назначения и макросы профиля.
Это конфигуратор; он не перепрошивает геймпад.

## English

Experimental portable Windows 10/11 x64 build. Extract the
entire ZIP and run `Vader5Control.exe`; GTK/Python/SDL are included.

Features: device status/input tester, persistent ten-channel lighting,
up to ten animation frames, brush/presets, Steam SDL patch with registry
path detection, Flashplay setup, RU/EN and blue-accent light/dark themes.

Close Steam and Space Station before patching or changing hardware settings.
Original Steam libraries are backed up. Reapply after Steam updates if needed.

Known issues: Bluetooth disconnects; no full three-axis Flashplay gyro;
tester-to-Steam handoff and startup duration need more real Windows feedback.
Use `Launch.cmd` or `Diagnose-Startup.cmd` for logs. Hardware configuration
uses the dongle; incompatible 7.2 writes are blocked. RGB save also commits
profile mappings/macros. No controller flashing is performed.
