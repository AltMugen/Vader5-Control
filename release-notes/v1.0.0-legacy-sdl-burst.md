# Flydigi Vader 5 Pro Linux v1.0.0 — Legacy SDL Burst

[English](#english) | [Русский](#русский)

---

## English

This release preserves the original SDL3 rumble and input fix for the Flydigi Vader 5 Pro 2.4G dongle (`37d7:2401`).

### Included

- Patched SDL3 with a two-burst rumble sequence, a 22 ms safety window, and report deduplication for the receiver's pause on vendor HID interface 1.
- The `vader5` utility for switching between Steam Native and Padctl modes.
- An installer that builds the patched SDL3, installs udev rules, and sets up Padctl.
- Direct SDL library replacement in Steam with the original file size preserved.

### Installation

Install the dependencies listed in the README for your distribution, then run:

```bash
./install.sh
```

Close Steam before applying or updating the SDL libraries.

### CLI

```bash
vader5 native
vader5 padctl
vader5 update
vader5 status
```

## Русский

Эта версия сохраняет исходный фикс ввода и вибрации SDL3 для Flydigi Vader 5 Pro с 2.4G-донглом (`37d7:2401`).

### Что входит

- Пропатченная SDL3 с двойным залпом вибрации, окном безопасности 22 мс и дедупликацией отчётов для пауз приемника на вендорном HID-интерфейсе 1.
- Утилита `vader5` для переключения между Steam Native и Padctl.
- Установщик, который собирает SDL3, устанавливает правила udev и настраивает Padctl.
- Прямая подмена SDL в Steam с сохранением исходного размера файла.

### Установка

Установите зависимости из README для своего дистрибутива и запустите:

```bash
./install.sh
```

Перед установкой или обновлением SDL закройте Steam.

### Команды

```bash
vader5 native
vader5 padctl
vader5 update
vader5 status
```
