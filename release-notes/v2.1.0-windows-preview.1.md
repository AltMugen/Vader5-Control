# Vader5 Control v2.1.0-windows-preview.1

[English](#english) | [Русский](#русский)

## English

Windows x64 preview of Vader5 Control and the Steam SDL3 patch. No Padctl or background service.

- Flydigi HID input for the dongle, with grip rumble sent through Windows XInput.
- Flashplay Bluetooth through the Windows GATT API: extra buttons, sticks, triggers and two rumble channels. Default stream: about 100 reports/s.
- PowerShell installer discovers Steam, backs up original DLLs outside Steam, copies the patched library in place and preserves its original length.
- Separate restore action and a command to launch Steam with Flashplay enabled. English and Russian messages.

GUI startup and Bluetooth input have been reported working on Windows; reconnect timing with Steam still needs confirmation. Full Bluetooth IMU and independent trigger rumble are not implemented. XInput must identify a unique Vader 5 slot; the driver refuses ambiguous targets.

Extract the entire Windows x64 ZIP and run `Vader5Control.exe`. Close Steam before applying its patch from Overview. Usage and rollback: [Windows README](../windows/README.md).

## Русский

Предварительная Windows-сборка x64 Vader5 Control и патча SDL3 для Steam. Без Padctl и фонового сервиса.

- Ввод с донгла через HID Flydigi, вибрация основных моторов через штатный XInput Windows.
- Bluetooth Flashplay через GATT API Windows: дополнительные кнопки, стики, триггеры и два канала вибрации. По умолчанию около 100 отчётов/с.
- Установщик PowerShell находит Steam, сохраняет оригиналы вне его каталога и копирует DLL на месте с сохранением исходного размера.
- Отдельное восстановление и запуск Steam с включённым Flashplay. Сообщения на русском и английском.

Запуск GUI и Bluetooth-ввод подтверждены по обратной связи с Windows; время повторного подключения Steam ещё требует проверки. Полная IMU по Bluetooth и отдельная вибрация триггеров не реализованы. Для XInput требуется однозначно определяемый слот Vader 5; при неоднозначности команда не отправляется.

Распакуйте весь Windows ZIP x64 и запустите `Vader5Control.exe`. Для патча Steam закройте клиент и используйте кнопку в «Обзоре». Инструкция и откат: [README для Windows](../windows/README.md).
