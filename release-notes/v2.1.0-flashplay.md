# Flydigi Vader 5 Pro Linux v2.1.0 — Bluetooth Flashplay

[English](#english) | [Русский](#русский)

## English

This release adds an experimental Flashplay Bluetooth backend to the existing Steam SDL patch.

### Changes

- Extra controls, including C/Z, LM/RM, M1–M4, Fn and Turbo, are exposed through SDL over Bluetooth. Sticks, D-pad and analog triggers are included.
- Two grip-rumble channels use the controller's Bluetooth command directly. No rumble bridge is needed for Flashplay.
- The default Bluetooth stream delivers about 100 reports/s; the previous stream is available with `SDL_FLYDIGI_BT_STREAM_MODE=1`.
- `vader5 bluetooth` saves the controller and adapter addresses. Later launches use the normal Steam shortcut or `steam`.
- Dongle support, Xbox-interface rumble, Direwolf handling, SteamRT3 support and the Native/Padctl switcher are retained.
- Steam loads the patched SDL from the user driver directory. Its original libraries remain untouched by new installations.
- The regular Linux installer still installs Padctl by default. Use `SKIP_PADCTL=1` to omit it.

### Installation

Close Steam, extract the Linux x86_64 archive and run `./install-prebuilt.sh`. Source installation remains `./build.sh` followed by `./install.sh`.

For Flashplay, disconnect the controller from the phone, wake it and run:

```bash
vader5 bluetooth AA:BB:CC:DD:EE:FF
```

Use your own controller address. Add the adapter address as the second argument if automatic selection is ambiguous. Later launches use the normal Steam shortcut or `steam`.

### Bluetooth limitations

Full three-axis gyro, accelerometer, battery reporting, RGB control and independent trigger rumble are not exposed. One controller and one SDL process are supported. Wake the controller if reconnecting fails. The higher report rate is not a measurement of end-to-end input latency.

## Русский

В этой версии к существующему патчу SDL для Steam добавлен экспериментальный Bluetooth-драйвер Flashplay.

### Изменения

- По Bluetooth в SDL доступны дополнительные кнопки C/Z, LM/RM, M1–M4, Fn и Turbo, а также стики, крестовина и аналоговые триггеры.
- Два канала вибрации основных моторов управляются напрямую Bluetooth-командой геймпада. Сервис вибрации для Flashplay не требуется.
- По умолчанию используется поток около 100 отчётов/с. Прежний режим доступен через `SDL_FLYDIGI_BT_STREAM_MODE=1`.
- `vader5 bluetooth` сохраняет адреса геймпада и адаптера. Дальше Steam запускается обычным ярлыком или командой `steam`.
- Сохранены поддержка донгла, вибрация через Xbox-интерфейс, обработка Direwolf, поддержка SteamRT3 и переключение Native/Padctl.
- Steam загружает нашу SDL из каталога драйвера пользователя. Новая установка не подменяет оригинальные библиотеки клиента.
- Обычный Linux-установщик по-прежнему ставит Padctl. Для установки без него задайте `SKIP_PADCTL=1`.

### Установка

Закройте Steam, распакуйте Linux-архив x86_64 и запустите `./install-prebuilt.sh`. Установка из исходников: `./build.sh`, затем `./install.sh`.

Для Flashplay отключите геймпад от телефона, разбудите его и выполните:

```bash
vader5 bluetooth AA:BB:CC:DD:EE:FF
```

Укажите свой адрес. Если адаптеров несколько, добавьте MAC нужного вторым аргументом. В дальнейшем запускайте Steam обычным ярлыком или командой `steam`.

### Ограничения Bluetooth

Полный трёхосевой гироскоп, акселерометр, заряд батареи, RGB и независимая вибрация триггеров пока не предоставляются. Поддерживается один геймпад и один процесс SDL. Если повторное подключение не проходит, разбудите контроллер. Повышенная частота отчётов не является измерением полной задержки ввода.
