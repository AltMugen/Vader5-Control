# Vader5 Control 0.1 — Linux beta

GTK-конфигуратор Flydigi Vader 5 Pro и патчи SDL3 для Steam.

- Обзор, заряд, прошивки, доступ стороннего ПО и тестер ввода.
- Подсветка: штатные эффекты, 10 независимых RGB-каналов, до 10 кадров, кисть, пресеты и сохранение в геймпад.
- Native / Padctl, переключение и редактирование профилей Padctl.
- Патч вибрации через Xbox-интерфейс донгла; ввод дополнительных кнопок и гироскопа использует драйвер SDL.
- Первое подключение Bluetooth Flashplay из приложения.
- RU/EN, две темы, экспериментальные настройки стиков, триггеров и моторов.
- Установка ярлыка и иконок стандартных размеров для GNOME.

## Установка

Распаковать `Vader5Control-0.1-linux-x86_64.tar.gz` целиком.
Установить зависимости из README, закрыть Steam и выполнить:

```bash
./install-prebuilt.sh
./gui/install.sh
```

Запуск: `vader5-control` или ярлык в меню. Без Padctl:
`SKIP_PADCTL=1 ./install-prebuilt.sh`.

## Известные ограничения

Bluetooth экспериментальный: в Steam возможны обрывы, полный трёхосевой
гироскоп недоступен. Аппаратные настройки меняются через донгл.
Запись несовместимых профилей 7.2 заблокирована. Кривые стиков в Linux
доступны только для чтения. Сохранение RGB штатной командой также сохраняет
текущие назначения и макросы активного профиля.

SDL собрана для glibc 2.31+. GUI требует Python 3.11+, GTK 4.10+ и
libadwaita 1.5+. Готовая сборка x86_64; Steam установлен обычным пакетом,
Flatpak в этот выпуск не входит.

## English

First beta of the GTK configurator and Steam SDL3 patches. Includes device
status and input tester, persistent ten-channel lighting with up to ten
frames, presets and brush, Native/Padctl integration, extra dongle controls,
gyro, rumble and experimental Flashplay setup. RU/EN and light/dark themes.

Extract the full archive, install README dependencies, close Steam, run
`./install-prebuilt.sh` then `./gui/install.sh`. Run `vader5-control`.

Bluetooth can disconnect in Steam and does not provide full three-axis gyro.
Hardware configuration uses the dongle. Incompatible7.2 profile writes are
blocked; Linux stick curves are read-only. Lighting save also commits current
mappings/macros. GUI requires Python 3.11+, GTK 4.10+, libadwaita 1.5+.
