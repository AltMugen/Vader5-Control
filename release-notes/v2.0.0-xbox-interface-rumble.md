# Flydigi Vader 5 Pro Linux v2.0.0 — Xbox Interface Rumble

[English](#english) | [Русский](#русский)

---

## English

This release replaces the repeated-burst rumble workaround with a direct rumble path through the dongle's Xbox interface.

### Changes

- SDL3 reads the extra controls and gyro from HID interface 1.
- SDL rumble requests are sent over a user-session socket to the `vader5-rumble` service.
- The service sends rumble reports to interrupt OUT endpoint `0x05` on Xbox interface 0.
- `xpad` is detached from interface 0 so Steam does not register a duplicate controller.
- SDL is built from the pinned `release-3.4.4` tag using a maintained source patch.
- A small `SDL_TryLockJoysticks` shim is built for Steam UI compatibility; `$ORIGIN` runpaths let SteamRT3 resolve it in its isolated loader namespace.
- The updater keeps the original copy outside Steam's directories, then copies SDL in place and truncates it to the original file size.
- The RT3 client library (`steamrt64`) is patched along with the legacy Steam libraries.
- The default build targets 64-bit Steam libraries. Set `BUILD_32=1` to build and patch 32-bit libraries; stale 32-bit output is not used by a default build.
- Padctl is installed by default; set `SKIP_PADCTL=1` to omit it.
- The selected Native/Padctl mode persists after reboot. Native mode updates the USB access rule and starts the rumble service.
- SDL talks to the rumble service through an abstract Unix socket so SteamRT3 does not depend on a shared socket file. The service accepts commands only from the same user.

### Installation

Install the build dependencies listed in the README, then run:

```bash
./build.sh
./install.sh
```

Close Steam before installation. The udev rule and mode switching require administrator access. `vader5 update` does not need root when Steam is installed under the current user's home directory.

### CLI

```bash
vader5 native
vader5 padctl
vader5 update
vader5 status
```

## Русский

В этой версии повторные залпы заменены прямой передачей вибрации через Xbox-интерфейс донгла.

### Изменения

- SDL3 читает дополнительные кнопки и гироскоп через HID-интерфейс 1.
- Команды вибрации SDL отправляются через пользовательский сокет в сервис `vader5-rumble`.
- Сервис передаёт команды вибрации на interrupt OUT endpoint `0x05` интерфейса Xbox 0.
- `xpad` отключается от интерфейса 0, чтобы Steam не создавал второй геймпад.
- SDL собирается из закреплённого тега `release-3.4.4` с отдельным исходным патчем.
- Для совместимости Steam UI собирается небольшой shim с символом `SDL_TryLockJoysticks`; `$ORIGIN` помогает SteamRT3 найти его в изолированном загрузчике.
- Оригинал SDL хранится вне каталогов Steam; новая библиотека копируется на месте и обрезается до исходного размера.
- Патч применяется к клиенту RT3 (`steamrt64`) и legacy-библиотекам Steam.
- По умолчанию собираются 64-битные библиотеки Steam. Для 32 бит задайте `BUILD_32=1`; оставшиеся файлы от старой сборки не используются.
- Установщик ставит Padctl по умолчанию; задайте `SKIP_PADCTL=1`, чтобы пропустить его.
- Выбранный режим Native/Padctl сохраняется после перезагрузки. Native обновляет правило доступа к USB и запускает сервис вибрации.
- Для SteamRT3 связь SDL с сервисом вибрации перенесена на абстрактный Unix-сокет: общий файл сокета больше не требуется. Сервис принимает команды только от того же пользователя.

### Установка

Установите зависимости из README и запустите:

```bash
./build.sh
./install.sh
```

Перед установкой закройте Steam. Для правила udev и переключения режимов нужен доступ администратора. Команда `vader5 update` не требует root, если Steam установлен в домашний каталог текущего пользователя.

### Команды

```bash
vader5 native
vader5 padctl
vader5 update
vader5 status
```
